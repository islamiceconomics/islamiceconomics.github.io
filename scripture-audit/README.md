# Scripture database quarantine

The public scripture database was taken offline on 2026-07-15 after citation and attribution errors were identified.

The quarantined files in this directory are retained only as audit working material. They are outside `Website/`, so GitHub Pages does not publish them.

Before reactivation, every entry must be checked source by source for:

- surah name, surah number, ayah number, Arabic text, and translation;
- hadith collection, book/edition, numbering system, Arabic text, translation, and grading;
- duplicate or recycled references;
- direct source links and review provenance.

Do not move these files back into `Website/` or restore the scripture loaders until the audit is complete and the public pages have passed a final review.
